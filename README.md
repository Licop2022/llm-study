# 研究工作台

个人科研学习工作台，论文学习与项目实践分区，含专题路线、词汇与概念专项、目录式知识图谱、笔记和实验记录。保留广东工业大学校徽，非学校官方网站。

此仓库由本地工具按清单生成；在本地原项目修改后重新生成并推送。浏览器笔记、日志、待办只保存在当前浏览器；在“记录与备份”中导出/导入 JSON 可迁移地址或设备，不会通过 GitHub 自动同步。

GitHub Pages：Settings → Pages → Source 选择 GitHub Actions，main 分支推送后自动发布。

第三方 PDF、标识及截图中的原作品归原作者，资源来源见 assets/SOURCES.md 与文献导读。
