# 三模块流程与预测基线复盘

## 目的

将阶段汇报中的 D2 路线从公式推进到可运行代码，分别确认环境、张量表示、压缩、跨训练边界的特征构建和真实未来预测。

## 数据与已记录环境

张量形状 25×100×3×1500，轴依次为电池、采样点、指标、循环。指标为电流 mA、电压 V、容量 mAh。服务器环境已记录为 Python 3.12、PyTorch 2.10.0+cu128，RTX 6000 Ada 48GB。此前这些运行指定物理卡 2；不表示该卡一直空闲。

时间区间按 Python 索引划分：训练 `[0,1050)`、验证 `[1050,1200)`、测试 `[1200,1500)`。归一化仅拟合训练观测。历史 25、预测 5、滑动步进 1。

## 关键运行与结果

| 阶段 | 截图确认的结果 | 意义与边界 |
|---|---|---|
| 合成 GPU 检查 | 最终测试 RMSE 0.000126，均值基线 0.998305 | 验证计算链；不是电池预测 |
| 模块一，12/50、min-max | 留出元素测试 RMSE 0.031188 | 训练前缀内补全；不是未来预测 |
| 初次模块二 | 压缩前后元素测试 RMSE 0.031188 → 0.025035 | 该次重建改善，不保证跨时间推广 |
| 训练/部署核来源检查 | 同一训练样本，旧 codec 容量误差约 20.001 → 86.625 mAh | 输入从 Adam 核换成 ridge 核时性能退化，暴露接口不一致 |
| 对齐核来源并重训 codec | 验证同周期容量曲线 RMSE 88.768 → 23.636 mAh | 修复交接问题；不是未来预测成绩 |
| 直接输出 Transformer，20 轮 | 测试 SOH MAE 6.450 个百分点 | 第一次真实未来预测，未超过基线 |
| 残差 Transformer，100 轮 | 测试 SOH MAE 4.369 个百分点 | 比直接输出改善，仍未超过原始容量持续基线 |

对齐操作固定 A/B 和缩放，用相同 ridge 规则重新推断训练核，然后重训 codec 并重新生成预测输入。它不是单纯把测试值替换进模型。
